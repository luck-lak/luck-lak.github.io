Git 团队协作全流程（速查笔记）

前置准备（仅首次）

git clone <仓库地址>

9步流程

步骤目的命令
① 明确需求看 Issue/文档，确认要改什么无（网页操作）
② 同步远程查看队友有没有新提交git fetch origin
③ 切分支基于最新 dev 创建个人分支git checkout dev → git pull origin dev → git checkout -b feature/xxx
④ 开发提交本地多次存档git add . + git commit -m "信息"（重复）
⑤ 推送远程上传分支到 GitHubgit push origin feature/xxx
⑥ 发起 PR申请合并到 dev网页操作：base=dev，compare=feature/xxx
⑦ 修改代码按 review 意见改，再推送git add . + git commit -m "fix: ..." + git push origin feature/xxx（重复）
⑧ 合并 PR审核通过，点 Merge 合入网页点 Merge 按钮，合并后删远程分支
⑨ 关闭 Issue自动关任务，记录变更PR 描述写 Closes #编号

命令速查

git fetch origin                              # 看远程更新
git checkout dev && git pull origin dev       # 更新本地 dev
git checkout -b feature/xxx                   # 创建并切换新分支
git add . && git commit -m "信息"             # 提交
git push origin feature/xxx                   # 推送到远程

核心概念

origin 远程仓库默认名

dev 开发主分支（团队基地）

feature/xxx 个人开发分支

fetch 只看远程更新，不合并不改动

pull fetch + merge，拉取并合并

push 上传本地提交到远程

PR 请求合并代码（需审核）

口诀

先看任务再同步，切出分支做改动 → 多次提交推送 PR，审完再改点合并 → 关掉任务记一笔
