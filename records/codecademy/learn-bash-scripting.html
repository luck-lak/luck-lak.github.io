Course Summary

Take a minute to review what you’ve learned about bash scripting.

  • Any command that can be run in the terminal can be run in a bash script.
  • Variables are assigned using an equals sign with no space (greeting="hello").
  • Variables are accessed using a dollar sign (echo $greeting).
  • Conditionals use if, then, else, fi syntax.
  • Three types of loops can be used: for, while, and until.
  • Bash scripts use a unique set of comparison operators:
  • Equal: -eq
  • Not equal: -ne
  • Less than or equal: -le
  • Less than: -lt
  • Greater than or equal: -ge
  • Greater than: -gt
  • Is null: -z
  • Input arguments can be passed to a bash script after the script name, separated by spaces (myScript.sh “hello” “how are you”).
  • Input can be requested from the script user with the read keyword.
  • Aliases can be created in the .bashrc or .bash_profile using the alias keyword.

Notes and Takeaways

主要是在讲一个一般流程：

① 写 Bash 脚本

↓

script.sh

② 第一行写

#!/bin/bash

③ 给它执行权限

chmod +x script.sh

④ 把脚本放到

~/bin/

⑤ 在 ~/.bashrc 中加入

PATH=~/bin:$PATH

⑥ 重新打开终端

⑦ 以后可以直接：

script.sh

总体下来，这节课还是挺有意思的，只需要花很短的时间，可以了解一些常见的技术，属于是计算机常识。

我认为在AI 时代这些基本了解，可以让我们在理解AI做了什么的时候更容易，也可以更好地知道怎么使唤AI 做使用这个技术的事情

Final Project Build Script

</> Bash
#!/bin/bash

echo "Welcome to the build script!"

firstline=$(head -n 1 changelog.md)

read -a splitfirstline <<< $firstline

version=${splitfirstline[1]}

echo "You are building version $version."

echo "Is this the correct version?"
echo "Enter 1 to continue, or 0 to exit."

read versioncontinue

if [ $versioncontinue -eq 1 ]
then
  echo "OK"

  for filename in source/*
  do
    echo "Found file: $filename"

    if [ $filename == "source/secretinfo.md" ]
    then
      echo "$filename is not being copied."
    else
      echo "$filename is being copied."
      cp "$filename" build/
    fi
  done

  cd build/

  echo "Build version $version contains:"
  ls

  cd ..
else
  echo "Please come back when you are ready"
fi

Annotated Build Script

</> Bash · annotated
#!/bin/bash
# Shebang：告诉系统使用 Bash 来执行这个脚本

# 输出欢迎信息
echo "Welcome to the build script!"

# 使用 head 命令读取 changelog.md 的第一行
# $(...)：执行命令，并把命令的输出保存下来
# 所以 firstline 里保存的是 changelog.md 的第一行
firstline=$(head -n 1 changelog.md)

# 把 firstline 按空格拆分成数组
# -a：将输入保存到数组 splitfirstline 中
# <<<：把变量的内容作为输入传给 read
#
# 例如：
# firstline="## 1.2.0"
#
# 那么：
# splitfirstline[0] = "##"
# splitfirstline[1] = "1.2.0"
read -a splitfirstline <<< $firstline

# 取数组中的第 2 个元素（下标为 1）
# 得到版本号，例如：1.2.0
version=${splitfirstline[1]}

# 输出当前正在构建的版本
echo "You are building version $version."

# 询问用户是否确认这个版本
echo "Is this the correct version?"
echo "Enter 1 to continue, or 0 to exit."

# 读取用户输入，并保存到 versioncontinue
read versioncontinue

# 判断用户输入是否等于 1
# -eq = equal，表示数字相等
if [ $versioncontinue -eq 1 ]
then
  echo "OK"

  # 遍历 source/ 目录中的所有文件
  # 每次循环时，filename 就代表当前找到的文件
  for filename in source/*
  do

    # 输出当前找到的文件
    echo "Found file: $filename"

    # 判断当前文件是不是 secretinfo.md
    if [ $filename == "source/secretinfo.md" ]
    then

      # 如果是秘密文件，就不复制
      echo "$filename is not being copied."

    else

      # 如果不是秘密文件，就复制到 build/ 目录
      echo "$filename is being copied."
      cp "$filename" build/

    fi

  done

  # 进入 build/ 目录
  cd build/

  # 显示构建完成后的版本信息
  echo "Build version $version contains:"

  # 列出 build/ 目录中的文件
  ls

  # 返回上一级目录
  cd ..

else

  # 如果用户没有输入 1，就不进行构建
  echo "Please come back when you are ready"

fi
